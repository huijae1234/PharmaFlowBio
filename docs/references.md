# references.md — 어떤 레퍼런스를 Claude에게 보여 줬나

화면을 상상으로 만들지 않고 "이런 느낌으로" 요청하려고 모은 레퍼런스와, 그것을 어디에 썼는지의 기록입니다.
캡처 이미지는 원작자와 출처를 확인할 수 없는 다른 사람의 디자인이라, 포트폴리오 사본에서는 저장소와 지난 커밋 기록에서 모두 뺐습니다(2026-11-05). 아래 표는 무엇을 보고 무엇을 가져왔는지를 글로만 남긴 것입니다. 화면 디자인 결정의 이유는 `CLAUDE.md`의 "UI 개편" 항목에 있습니다.

- 보여 준 방법은 모두 **이미지를 Claude Code 대화에 붙여 넣은 것**입니다.
- 낸 곳(원 작성자·링크)은 이미지만 받았기 때문에 **확인하지 못했습니다**. 캡처에 보이는 서비스 이름만 적었고, 출처 링크는 아는 대로 채워 주세요.
- 모두 화면의 배치·색·모양을 **참고**한 것이고, 로고·글·그림·사진은 가져오지 않았습니다.

## 2. 레퍼런스를 보고 정한 것 (요약)

| 정한 것 | 이유 |
|---|---|
| 톤: 밝고 투명한 "클리니컬 글라스", 주색은 제약·백신에 맞는 청록(#0b6e8a), 포인트는 라임(#d7f34a) | 8번 레퍼런스를 마음에 들어 했고, 팔레트는 후보 4개(청록·인디고·메디컬 그린·슬레이트+앰버)를 같은 화면에 그려 보고 A안(청록)으로 확정 |
| 라임은 "지금 해야 할 것"에만 | 1·2번처럼 포인트색이 한 곳에서만 쓰여야 시선이 간다 |
| 모서리는 카드 8px, 버튼·입력 6px, 배지 4px | 5번을 따라 둥글게 했다가 "너무 동그랗다"는 피드백으로 줄임 |
| 큰 숫자는 얇게, 단위는 작게 | 8·9번 |
| 도식은 이미 있는 자료로만 (도넛·주별 이슈·이탈 순위) | 합성 데이터를 더 만들지 않는다는 원칙. 4·6·7번에서 구성만 참고 |
| 목록 + 미리보기, 거르기 칩 | 2번 |
| 공정 단계는 동그라미 아래에 그 단계 내용 (세로로 바뀔 때도 옅은 선으로 연결), "1/5" 대신 "전체 5단계 중 1번째" | 사용자 피드백 (날짜·진행률로 오해할 수 있음). 레퍼런스에서 가져온 것이 아님 |

## 3. 출처 링크

- 레퍼런스는 이미지로만 받아서 원 작성자·출처 링크(Dribbble·Behance 등)는 확인할 수 없습니다. 캡처에 보이는 서비스 이름만 적었습니다(2026-10-29 김희재 확인: 링크 없이 둔다).
- 같은 이유로 캡처 이미지는 공개 저장소에 두지 않습니다(2026-11-05 김희재 결정, 지난 커밋 기록에서도 뺌).
