- 최종 갱신: 2026-10-28

## 돌리는 법

|---|---|---|
| 함수 시험 (자료 파일을 읽음) | `node --test "tests/*.test.js"` (`tests/fixtures.test.js`) | 쓰지 않음 |
| DB 시험 (같은 값으로 판정·저장·중복·권한) | `supabase/tests/019_rules.sql`을 Supabase SQL로 실행. 끝에서 일부러 오류를 내 모두 되돌린다. "PF_TEST 통과 N/N"이면 통과 | 남기지 않음 |
| 공공데이터 시험 모드 | 미리보기 `pharmaflow-fixtures` 설정, 또는 `PUBLIC_DATA_MODE=fixtures node --env-file-if-exists=.env server.js`. 끄려면 `pharmaflow` 설정(환경변수 없음) | 쓰지 않음 |
