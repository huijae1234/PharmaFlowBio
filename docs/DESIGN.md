# DESIGN.md — PharmaFlow Bio 화면 디자인 결정

화면을 어떻게, 왜 이렇게 만들었는지의 기록입니다. 값은 `styles/tokens.css`가 원본이고, 이 문서는 이유를 적습니다.
레퍼런스와 가져온 부분은 [references.md](references.md), 구현 메모는 `CLAUDE.md`의 "UI 개편" 항목에 있습니다.

## 1. 한 줄 원칙

**"지금 내가 할 일"이 가장 먼저 보이고, 판단에 필요한 비교는 화면을 오가지 않고 한 화면에서 한다.** 톤은 밝고 투명한 "클리니컬 글라스".

시작점: 사용자가 홈 화면을 가장 답답하게 느꼈다("뭘 해야 하는지 모르겠고, 파악하는 데 시간이 너무 오래 걸린다"). 그래서 장식보다 **할 일 → 현황 → 도식** 순서의 정리를 먼저 했다.

## 2. 색

| 쓰임 | 값 | 이유 |
|---|---|---|
| 주색(버튼·링크) | `#0b6e8a` 청록 | 백신·제약 분위기. 흰 글자와 명암비 5.7:1 |
| 포인트 | `#d7f34a` 라임 (글자는 `#26330a`) | **"지금 해야 할 것"에만** 쓴다(할 일 카드 띠, 메뉴 건수, 현재 단계). 여러 곳에 쓰면 시선이 흩어진다 |
| 바탕 | `#eef4f9` + 옅은 하늘·민트·연보라 빛 번짐 | 카드가 투명해 보이려면 뒤에 색이 있어야 한다. 진하게 하면 글자가 불편해서 옅은 쪽으로 정했다 |
| 글자 | `#0f2233` / 보조 `#4a6075` | 흰 바탕 명암비 4.5:1 이상 |
| 정보·시험 중 | `#3b5bdb` | 주색(청록)과 구분 |
| 성공·주의·위험 | `#1e9e62` / `#c77700` / `#d1344b` | 상태는 색만이 아니라 **글자로도** 쓴다 |

**후보 비교:** 같은 홈 화면에 팔레트 네 개를 그려 보고 고름 — A 백신 청록(채택), B 인디고, C 메디컬 그린, D 슬레이트+앰버. 배경색은 한 번 진하게 했다가 "이전이 낫다"는 피드백으로 옅게 되돌렸다.

## 3. 글꼴·크기·간격

- 본문 Pretendard, 로트번호·코드·숫자 JetBrains Mono (같은 폭 숫자).
- 글자 크기 12/14/16/20/24/32, 큰 숫자 40. **큰 숫자는 굵기 300(얇게), 단위는 작게**(예: 7건, 2.0일). 레퍼런스 8·9번.
- 간격은 4/8/12/16/24/32 단계만 쓴다.

## 4. 모양

- **유리 카드:** 흰색 55% 불투명 + 배경 흐림(18px) + 흰빛 테두리 + 아주 옅은 그림자.
- **모서리:** 카드 8px, 버튼·입력 6px, 배지·칩 4px. 처음에는 16/12/알약이었는데 "너무 동그랗다, 조금 네모네모하게"라는 피드백으로 줄였다.
- **옆 메뉴:** 밝은 반투명. 현재 메뉴는 흰 알약 + 왼쪽 라임 바. 묶음 이름(업무/기준정보/관리)은 일반 탭과 헷갈린다는 피드백으로 **아주 작은 글자 + 이름 아래 메뉴를 왼쪽 세로선에 딸리게 들여쓴 트리 모양**으로 바꿨다(묶음 사이 가로선은 뺌).

## 5. 화면 구성

### 홈 (넓은 화면 1200px 이상)
- **두 줄.** 윗줄 큰 칸 2개(지금 할 일 · 보류 로트), 아랫줄 같은 크기 칸 4개(로트 상태 도넛 · 주별 품질 이슈 · 이탈이 많은 항목 · 회수 공지).
- 그래프는 서로 가까이 둔다(옆으로 길게 늘리지 않는다). 카드는 한 줄 높이를 채워 빈칸이 남지 않는다.
- 1200px 미만 2칸, 700px 미만 1칸으로 쌓인다.
- 사이드바 "홈" 옆에 지금 할 일 건수를 배지로 보여 준다.
- 도식은 **이미 있는 자료로만** 그린다(합성 데이터를 더 만들지 않는다는 원칙).

### 로트·품질 이슈 목록
- 거르기 칩 + 목록 + 미리보기(`ui/master-detail.js`). 로트 목록은 로트번호 앞 글자가 제품과 1:1이 아니라서 **제품(product_id) 기준**으로 거른다.

### 로트 상세 "공정 단계"
- 넓은 화면에서 각 단계 동그라미 **바로 아래에 그 단계 내용**이 오게 맞췄다(한 단계 = 한 칸).
- 좁은 화면에서는 세로로 쌓이고, 동그라미 아래로 옅은 선이 이어져 한 흐름으로 보인다.
- **"1/5" 표기를 없앴다.** 날짜나 "5단계 중 4단계만 했다"로 읽힐 수 있어서 "전체 5단계 중 **4번째**"(몇 번째만 진하게)로 풀어 썼다.

### 비교 원칙
판단에 필요한 비교는 화면을 오가지 않게 한 화면에: 범위 막대, 같은 제품 로트 비교, 출하 판단 근거, 영향 평가 근거|평가 2열, 시험값 일괄 입력의 입력 중 판정.

## 6. 접근성·모바일

- 명암비 4.5:1 이상, 상태는 글자로도 표시, 도식은 범례의 글자·숫자와 화면 읽기용 설명을 함께 둔다.
- 모바일(375px)에서 가로 넘침 없음을 화면마다 확인했다. 눌러야 하는 곳은 44px 이상. 범위 막대의 값 설명은 휴대폰에서 눌러도 보인다.
- 좁은 화면에서도 같은 내용이 나오고, 칸만 한 줄로 쌓인다.

## 7. 하지 않은 것 · 아직 남은 것

- 문구 통일 15건(A-1~A-7 용어, B-1~B-8 설명 보강)은 사용자가 이번에는 제외했다.
- 폐기 사유 표시는 DB 마이그레이션 적용 뒤에만 값이 보인다.
