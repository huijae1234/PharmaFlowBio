- 커밋·PR 계정은 일의 크기도, 실제로 누가 썼는지도 정확히 말해 주지 않는다. 대부분의 PR이 유○○ 계정(`dbdpfla98`)으로 열렸다(Vercel 배포 때문, 팀 설명).
