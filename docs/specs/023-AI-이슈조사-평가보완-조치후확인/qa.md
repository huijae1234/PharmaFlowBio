> 이 문서는 **가짜 Claude 응답과 가상 자료**로 한 확인의 기록이다. **실제 Claude 응답으로 한 확인은 하나도 없다**(키 없음, 4절). "가짜 응답 통과"를 "실제 Claude 연동 완료"로 읽지 말 것. 조치 이후 비교(기능 3)는 예시 DB에 비교할 자료가 거의 없어 **실제 분석은 미확인**이고 가상 사례로만 확인했다.

## 2. 실제 화면 확인 (확인용 환경, Claude 실행)
**환경:** 실제 앱 코드(`src/` 전체, 이슈 상세·평가서 작성 창·조치 요청 창)를 브라우저에서 그대로 돌리고 **Supabase 저장소만 가짜 자료로 바꿨다**(구글 로그인은 자동화할 수 없고 운영 DB를 건드리면 안 되어서). `/api/ai`는 **실제 서버 함수**(`api/ai.js`)이며 **대상 이슈 확인(`checkTarget`)도 실제 코드**가 가짜 REST 응답을 읽는다. Claude 호출만 서버의 시험 모드(`AI_MODE=fixtures`)가 대신한다 → 화면의 출처 줄은 "시험 응답(실제 Claude 아님)". 환경과 가상 자료는 저장소 밖이다(`?follow=observed|none|few|short|fail|samelot|trunc` 등으로 조치 이후 자료를 바꾼다).

## 3. 이번에 화면 확인으로 찾아 고친 것
- 조치 종류를 고른 뒤에도 "먼저 골라 주세요" 안내가 남던 것, 결과·실패 화면에서 조치 종류 칸이 사라져 다른 종류로 다시 만들 수 없던 것(칸을 결과 뒤에도 남김), 설명 문구의 조사("단시간"라는 → "단시간" 표현).
- **숫자 검증이 기준 글자의 "110 %"를 못 읽어** 정상 문장("규격 90~110%")을 숫자 불일치로 막던 것(공백을 제거해 같은 수량으로 봄). spec 022 검증에도 같은 영향을 주는 변경이다(전체 시험 통과).

## 4. 실제 Claude로 확인하지 못한 것 (보스가 키를 넣은 뒤)

|---|---|---|

## 5. 검토 기록
