## 0. 요약
spec 007의 FR-001~004를 3단계로 만든다. 1단계는 메뉴만 고친다. "내 첫 화면"을 "홈"으로 바꾸고, "예시 자료 되돌리기" 메뉴·화면·주소를 앱에서 뺀다. 2단계는 디자인 토큰 파일 한곳(`styles/tokens.css`)과 틀(`app.css`)을 "클린 틸"로 바꾸고, 글꼴·이름·로그인 화면을 맞춘다. 3단계는 데이터베이스 마이그레이션 0018로 새 예시 자료(가상 제품 3개, 로트 8개와 그 이슈·평가·조치·이력)를 넣는 함수를 만들고, 되돌리기 함수가 이 새 예시를 쓰게 한 뒤 실제 자료를 한 번 바꾼다(Q41). 표 구조는 바꾸지 않는다. 새 라이브러리도 없다.

- 0018은 0015·0017의 되돌리기를 다시 정의하므로, 지우는 순서(평가 → 측정값 → 조치 → 이슈 → 공정 기록 → 로트)를 그대로 지킨다.
- 배포된 앱과 같은 데이터베이스다. 3단계 적용 순간 배포 화면의 예시도 바뀐다(Q41 승인됨).

### 경계
- 항상 할 것: 시험 먼저, 단계 끝마다 함수 시험과 qa.md 기록, 출처 주석(`// spec 007 FR-…`), 고친 뒤 미리보기 캐시 새로 받기.
- 먼저 물을 것: spec에 없는 화면 구성 변경, 새 라이브러리, 커밋·push·PR·배포.
- 절대 하지 말 것: spec 5절 제외 범위(업무 규칙·권한·화면 구성 변경, 다크 모드, 되돌리기 DB 함수 삭제, 실제 자료, 아이콘 묶음), 사용자·역할·사용 기록 지우기, 시험 지우기로 실패 숨기기(003·004의 예시 기대값은 spec이 바꾼 것이라 고친다).
