## 1. 해결하려는 문제
**지금 방식:** 화면은 범용 업무 앱 느낌의 파란색(ant 스타일)이다. 왼쪽 메뉴 첫 줄은 "내 첫 화면"이고, 관리 메뉴에 시연 준비용 "예시 자료 되돌리기"가 보인다. 예시 자료는 가상 백신 A·B 두 제품과 로트 4개(VX-2610-001~004)에 예전 일반 의약품(PF-2610-*)과 개발 중 확인용 로트(QA-T-*)가 섞여 있다. [코드 src/ui/layout.js] [IA 주 메뉴] [CLAUDE.md 현재 코드]
**막히는 지점:**
- 발표 청중(제약·백신 회사 실무자)이 보기에 회사에서 쓰는 품질 시스템처럼 보이지 않는다. [2026-10-26 사용자]
- "내 첫 화면"은 메뉴 이름으로 어색하다. 흔히 쓰는 말은 "홈"이다. [2026-10-26 사용자]
- "예시 자료 되돌리기"는 실제 회사 앱에는 없는 메뉴라 시연 중에 눈에 띈다. [2026-10-26 사용자]
- 예시 자료가 적고 섞여 있어 이탈 → 평가 → 조치 → 종료 → 출하 검토의 여러 단계를 한 번에 보여 주기 어렵다. 이름도 "가상 백신 A"처럼 실감이 없다. [2026-10-26 사용자] [UJ CUJ-01]

## 2. 주요 사용자
**사용자:** 모든 역할(화면 디자인, 메뉴), QA 관리자(시연 진행), 발표 청중. [PRD §4]

### 이야기 1 — 제약 회사 품질 시스템처럼 깔끔한 화면 (P1)
- 장면: 누구든 로그인하면 흰 바탕에 짙은 청록 포인트, 옅은 청록 옆 메뉴, 정돈된 표와 상태 배지가 보인다. 모든 화면이 같은 색·글꼴·간격을 쓴다. [2026-10-26 사용자 결정 "클린 틸"]
- 왜 P1: 발표에서 가장 먼저 보이는 인상이다.
- 혼자 확인하는 방법: 로그인 → 홈, 로트 상세, 이슈 상세, 제품, 관리 화면을 차례로 열어 색·글꼴이 같은지 본다.

### 이야기 2 — 메뉴가 회사 앱답다 (P1)
- 장면: 왼쪽 메뉴 첫 줄이 "홈"이고, 관리 메뉴에 "예시 자료 되돌리기"가 없다. [2026-10-26 사용자]
- 왜 P1: 시연 중 어색한 메뉴를 없앤다.
- 혼자 확인하는 방법: QA 관리자로 로그인해 메뉴를 읽는다.

### 이야기 3 — 한 번에 여러 단계를 보여 주는 예시 자료 (P1)
- 장면: 로트 목록에 실제 백신 공장처럼 이름 붙은 가상 제품 3개와 로트 8개가 있고, 생산 중·시험 중·보류·출하 가능·폐기와 평가 승인 대기·조치 진행 중·보완 요청 같은 단계가 고루 보인다. [UJ CUJ-01] [PRD FR-17]
- 왜 P1: 발표에서 클릭 몇 번으로 흐름 전체를 보여 준다.
- 혼자 확인하는 방법: 홈 대시보드의 승인 대기·출하 검토 대기·보류 로트 칸에 각각 예시가 있다.

## 3. 핵심 기능과 요구사항

### FR-001 화면 디자인 "클린 틸" (P1, 전체 화면)
시스템은 모든 화면에 하나의 디자인 토큰 묶음(색·글꼴·간격·모서리)을 써야 한다. [2026-10-26 사용자 결정] [rules/design.md 1]
- 수용 기준
  1. **전제** 어느 화면 **결과** 바탕 흰색, 포인트 짙은 청록(#0F766E), 글자 짙은 남색(#0F172A), 옆 메뉴 바탕 옅은 청록(#F0F7F6), 모서리 6px, 그림자는 창(모달)에만 약하게
  2. **결과** 한글·영문·숫자 모두 Pretendard(한글과 영문의 높이·굵기를 맞춤, v0.3), 시험값·로트번호는 고정폭 글꼴(지금처럼 JetBrains Mono)
  3. **결과** 상태 배지(정상·관리기준 이탈·규격 이탈, 로트 상태, 평가 상태)는 지금처럼 색과 글자를 함께 쓰고, 성공·경고·위험 색은 새 포인트 색과 겹치지 않는다 (rules/design.md 5)
  4. **결과** 모든 글자와 배경의 명암비 4.5:1 이상, 키보드 초점이 보이고, 375px 폭에서 가로 스크롤이 없다 (rules/design.md 3·4·6)
  5. **결과** 왼쪽 위 이름은 "PharmaFlow Bio"
  6. **결과** 로그인 화면도 같은 디자인

### FR-002 메뉴 이름 "홈" (P1, 주 메뉴)
시스템은 주 메뉴의 "내 첫 화면"을 "홈"으로 보여야 한다. 누르면 지금처럼 역할별 첫 화면(관리자 대시보드·품질시험 홈·제조공정 홈·로트 목록)으로 간다. [IA 주 메뉴] [IA 용어 "첫 화면"]
- 수용 기준
  1. **전제** 로그인 **결과** 메뉴 첫 줄이 "홈"이고, 누르면 역할별 첫 화면
  2. **결과** 각 첫 화면의 제목(관리자 대시보드 등)은 그대로

### FR-003 "예시 자료 되돌리기" 메뉴·화면 삭제 (P1, AD_050000_PU)
시스템은 앱에서 "예시 자료 되돌리기" 메뉴와 화면을 보여 주지 않아야 한다. 데이터베이스의 되돌리기 기능은 남겨, 필요하면 개발자가 직접 실행한다. [2026-10-26 사용자 결정 "메뉴·화면만 삭제"] [IA AD_050000_PU]
- 수용 기준
  1. **전제** QA 관리자 로그인 **결과** 관리 메뉴에 "예시 자료 되돌리기"가 없다
  2. **전제** 예전 주소(`#/admin/reset`)를 직접 연다 **결과** 없는 화면 안내(지금 다른 없는 주소와 같은 처리)
  3. **결과** 데이터베이스의 되돌리기 함수와 그 시험은 그대로 동작한다 (FR-004의 새 예시를 다시 넣는다)

### FR-004 새 예시 자료 (P1, 로트·품질 이슈·제품 화면)
시스템은 아래 가상 제품 3개, 로트 8개를 예시로 가져야 한다. 모든 제품·로트·시험값·기준은 교육용 가상 자료이며 화면에 "(가상)" 또는 "교육용 가상 기준"이 보인다. [PRD FR-17] [spec 004 FR-010] [문제정의 v2 머리말]
- 수용 기준
  1. **결과** 아래 "핵심 자료"의 제품·기준·로트·이슈·평가·조치 상태가 그대로 보인다
  2. **결과** 홈 대시보드에서 승인 대기(평가 1), 내부 출하 검토 대기(1개 이상), 보류 로트(2개)가 보인다
  3. **결과** 각 로트의 업무 이력이 그 상태에 이르는 순서대로 남아 있다(누가·언제)
  4. **결과** 예시를 넣고 지우는 작업은 사용자·역할·사용 기록을 건드리지 않는다
  5. **결과** 데이터베이스 되돌리기를 실행하면 이 새 예시로 돌아간다

### FR-005 품질 이슈 상태 이름 "처리 중 · 종결" (P1, 품질 이슈 목록·상세, 로트 상세, 홈)
시스템은 품질 이슈 상태를 "열림/닫힘" 대신 "처리 중/종결"로 보여야 하고, 같은 뜻의 버튼·단계·안내 문구도 같은 말을 써야 한다. 저장된 값(open·closed)은 바꾸지 않는다. [2026-10-26 사용자 결정]
- 수용 기준
  1. **결과** 상태 배지와 목록 거르기가 "처리 중", "종결"
  2. **결과** 버튼·창 제목 "품질 이슈 종결", 단계 표시줄 "이슈 종결", 다음에 할 일 "이슈 종결"
  3. **결과** "열린 품질 이슈" → "처리 중인 품질 이슈", "닫힌 이슈 없음" → "종결된 이슈 없음", 재시험 안내 "이슈를 종결할 수 있습니다"·"이슈는 처리 중으로 남습니다"
  4. **결과** 종결할 수 없는 이유와 데이터베이스가 보내는 문구도 "종결할 수 없습니다", "처리 중인 품질 이슈가 N건 있어 출하할 수 없습니다", 업무 이력 이름 "품질 이슈 종결" (예전 이력 줄의 글자는 그대로 둔다)

### FR-006 긴 주성분 줄이기 (P2, 제품 목록·제품 상세)
시스템은 제품 목록과 제품 상세 위쪽의 주성분을 두 줄까지만 보여 주고, 전체는 마우스를 올리면 보여야 한다. [2026-10-26 사용자: "주성분이 너무 길어서 스크롤이 길어짐"]
- 수용 기준
  1. **전제** 주성분이 수백 자인 백신 제품 **결과** 목록 한 줄과 상세 위쪽이 두 줄을 넘지 않고, 표가 옆으로 길게 밀리지 않는다
  2. **결과** 허가정보 탭의 주성분(공공데이터 원문)은 그대로 전체를 보여 준다

### FR-007 MSDS는 홈 아래 링크 (P2, HM_010000~030000, MS_010000_PG)
시스템은 주 메뉴에서 "MSDS"를 빼고, 각 역할의 홈(관리자 대시보드·품질시험 홈·제조공정 홈) 맨 아래에 공단 MSDS 조회로 가는 링크를 보여야 한다. 링크만 있던 MSDS 화면과 주소는 없앤다. [2026-10-26 사용자 결정] [spec 003 v0.3 FR-006, D13]
- 수용 기준
  1. **결과** 메뉴에 "MSDS"가 없다
  2. **결과** 세 홈 맨 아래 "물질안전보건자료(MSDS)" 칸에 공단 사이트로 가는 버튼 모양 링크(새 창, v0.4)
  3. **결과** 예전 주소(`#/msds`)는 없는 화면 처리

### FR-008 로트·제품 검색 (P2, BT_010000_PG, PD_010000_PG)
시스템은 로트 목록과 제품 목록에 검색 칸을 두고, 입력한 글자가 들어간 줄만 보여야 한다. [2026-10-26 사용자 요청 v0.4]
- 수용 기준
  1. **전제** 로트 목록 **행동** "HBV" 입력 **결과** 로트번호나 제품 이름에 "HBV"(대소문자 상관없이)가 들어간 로트만. 로트 상태 거르기와 함께 쓸 수 있다
  2. **전제** 제품 목록 **행동** "인플루엔자" 입력 **결과** 품목명·주성분·제조원에 그 글자가 들어간 제품만
  3. **행동** 검색어를 지운다 **결과** 다시 전체
  4. **전제** 맞는 줄이 없음 **결과** "검색 결과가 없습니다. 검색어를 바꿔 보세요."
  5. **결과** 검색어는 주소에 남아 새로 고쳐도 그대로다

### 경계·예외 상황
- 업무 규칙은 그대로: 예시 자료도 판정·보류·닫기 조건을 지킨 상태여야 한다(예: 닫힌 규격 이탈 이슈에는 승인된 평가와 완료된 조치가 있다). (FR-004)
- 지금 있는 예시·확인용 자료(가상 백신 A·B, VX-2610-001~004, PF-2610-001~005, QA-T-001~005, 그 품질 이슈·측정값·평가·조치)는 새 예시로 바뀐다. 업무 이력은 지우지 않고 로트 연결만 비운다(로트번호는 남음, 되돌리기와 같은 방식). (Q41) (FR-004)
- 허가정보로 등록한 실제 제품(타이레놀정500·엑스프리벤정)을 남길지 (Q42) (FR-004)
- 휴대폰 폭에서 옆 메뉴는 지금처럼 위쪽 "메뉴" 버튼으로 연다. (FR-001)
- 다크 모드는 만들지 않는다(업무 앱, 발표 화면 기준). (FR-001)

## 4. 성공 기준

### 완료 확인
- **SC-001**: 로그인·홈·로트 목록·로트 상세·이슈 상세·제품·관리 화면이 모두 새 색·글꼴·모서리를 쓰고, 명암비 4.5:1 이상·키보드 초점·375px 가로 스크롤 없음을 지킨다. (관련: FR-001)
- **SC-002**: 메뉴 첫 줄이 "홈"이고 역할별 첫 화면으로 가며, "예시 자료 되돌리기" 메뉴가 없고 예전 주소는 없는 화면 처리된다. (관련: FR-002, FR-003)
- **SC-003**: 로트 목록에 위 8개 로트가 표의 상태대로 있고, 홈 대시보드에 승인 대기 평가 1건·내부 출하 검토 대기·보류 로트 2개가 보인다. 예시 자료가 업무 규칙(닫기 조건 등)과 어긋나지 않는다. (관련: FR-004)
- **SC-006**: 화면과 데이터베이스 문구 어디에도 품질 이슈 상태를 "열림·닫힘·닫기"로 쓰지 않고 "처리 중·종결"로 쓴다(코드 이름·저장 값·예전 이력 글자 제외). (관련: FR-005)
- **SC-007**: 백신 제품 목록·상세에서 주성분이 두 줄을 넘지 않고, 메뉴에 MSDS가 없으며 세 홈 아래에서 공단 MSDS로 갈 수 있다. (관련: FR-006, FR-007)
- **SC-008**: 로트 목록에서 "HBV", 제품 목록에서 "인플루엔자"를 넣으면 맞는 줄만 보이고, 지우면 전체가 돌아온다. MSDS는 버튼 모양이다. (관련: FR-007, FR-008)
- **SC-004**: 기존 함수 시험과 DB 시험(되돌리기 시험은 새 예시 기준으로)이 모두 통과하고, 사용자·역할·사용 기록은 그대로다. (관련: FR-003, FR-004)
