## 0. 요약
- 범위: FR-001~006.
- 접근: main은 GE가 갈라진 뒤 `styles/`를 바꾸지 않았다. 그래서 GE의 스타일 차이를 거의 그대로 옮길 수 있다. 다만 GE의 새 화면 요소용 규칙(메뉴 묶음·건수, 칩, 목록+미리보기, 홈 카드 등)은 빼고, 좁은 화면 메뉴 규칙은 지금 메뉴 모양(`.nav-list`)에 맞춘다. GE처럼 톤 덮어쓰기는 `styles/glass.css` 한 파일에 모아 마지막에 불러온다. 나중에 GE의 다른 요소를 가져올 때 같은 파일 구조라 충돌이 적다.
- 단계: 2단계 — ① 스타일 옮기기와 화면 확인 ② 문서(CLAUDE.md 디자인 절·IA·Intent)와 사람 QA 목록.

- `backdrop-filter`가 없으면 반투명 흰 바탕만 보인다.

- 항상 할 것: 색은 토큰만, 명암비 계산, 출처 주석("GE 브랜치 cb5d46c·afe4c07, 윤○○").

- 절대 하지 말 것: 메뉴 묶음·건수, 칩 거르기, 목록+미리보기, 홈 도식·지금 할 일 카드, 비교 패널, 폐기 사유(DB), GE 전용 CSS(kit·home·lot·charts), 어두운 모드(spec 5절). 화면 글자·기능 바꾸기.
