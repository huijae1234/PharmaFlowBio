## 3. 실패와 조치
- 시험 자료 1차에서 승인이 같은 줄 3번 겹쳐 보임 → 시험 모드가 뒤쪽 쪽에는 빈 응답을 주게 고침.
- 시험 자료 업체명이 "(시험 자료)"로 끝나 "비슷한 이름" 시험이 안 됨 → 업체명 정리에서 그 표시를 뺌.
- (2026-10-29, H-02) 국가출하승인을 앞 3쪽만 받아 "최근 승인"이 2016~2019 자료로 나올 뻔함(실제 API가 접수 순서로 쌓임) → `api/shipment.js`가 건수 1건을 먼저 받고 끝 4쪽을 받게, 가장 이른 판정일(`since`)을 돌려주게 고침. 범위 글자는 `regulatory-rules.js` `scanRangeText`. 시험을 먼저 바꿔 실패 4건 확인 → 고친 뒤 통과. 함수 시험 276/276
- (2026-10-29, 배포 확인) 실제 백신 2개(유비콜-플러스, 지씨플루주)를 등록해 배포된 곳에서 보니 GMP 칸이 "찾은 GMP 적합판정서가 없습니다"로 나옴. 서버는 녹십자 8건·유바이오로직스 4건을 돌려줬는데, 실제 응답의 유효기간이 `2027-02-27`(하이픈)이라 `gmpRow`가 빈칸으로 읽고 `latestGmp`가 모두 뺌(시험 자료는 `20270227`이라 놓침) → `gmpRow`가 하이픈을 빼고 읽게 고침. 시험 `tests/regulatory-real-format.test.js` 2개를 먼저 써 실패 2건 확인 → 통과. 함수 시험 278/278. 로컬 화면: 지씨플루주 GMP 2029-11-30까지 1128일, 전체 8건 표, 업체명 대조 세 줄 모두 ✓ 같음
- (2026-10-29, 같은 확인) GMP 칸이 열리자 전체 8건 표(제형군 글자가 김, 줄바꿈 금지)가 공공데이터 칸을 1246px로 밀어 페이지가 가로로 넘침(폭 1108px에서 scrollWidth 1519) → `styles/public.css` `.public-panel`을 `minmax(0, 1fr)` 한 칸으로, 표가 든 묶음은 칸 너비로 늘려 넓은 표는 `.table-wrap` 안에서만 옆으로 넘김. 재확인: 데스크톱 1108/1108, 휴대폰 375/375(공개 규제 현황·허가정보 탭 모두), GMP 표는 795px 칸 안에서 1246px 스크롤
- (2026-10-29, PR #25 배포 확인) 배포된 곳에서 GMP 칸은 고쳐짐(지씨플루주 2029-11-30까지 1128일, 전체 8건, 허가정보↔GMP ✓ 같음). 그런데 국가출하승인 호출이 한 번 실패해 "마지막 정상 조회" 상자(`.last-good`)가 나오자 그 안의 GMP 표가 상자를 밀어 다시 넘침(1108 → 1531) → `.last-good`도 `minmax(0, 1fr)` 한 칸으로. 로컬에서 shipment·gmp 호출만 일부러 실패시켜 확인: 데스크톱 1108/1108(상자 795px), 휴대폰 375/375
