## Moment of Truth
- **3. 규격 이탈 → 자동 보류:** 생산 담당자가 직접 보류를 걸어야 한다면, 바쁜 생산 현장에서 늦거나 빠뜨리게 됩니다. 그러면 문제 로트가 내부 출하 검토 대상에 섞입니다. 관리기준 이탈은 보류하지 않고 이슈만 엽니다.

## 여정 명세 요점
- 공정 조건 하나라도 기준을 벗어나면 품질 이슈(발생 구분: 공정)가 1개 열린다. 같은 입력에서 여러 항목이 동시에 이탈해도 이슈는 1개이고, 이탈 항목이 모두 기록된다. 하나라도 규격 이탈이면 이슈 종류는 규격 이탈이다. (확정 2026-10-22, 종류 규칙은 v2 가정 → spec 004에서 확정)
- 설비 상태 "이상"은 숫자 기준이 없어도 규격 이탈로 본다. (확정 2026-10-22)
- 생산 담당자는 기준 이탈 없이도 사유를 적어 로트를 직접 보류할 수 있다 (BT_010207_MD).
