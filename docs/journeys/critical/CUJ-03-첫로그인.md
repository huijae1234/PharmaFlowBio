# CUJ-03: 첫 로그인부터 역할을 받아 내 첫 화면에 들어가기까지

- 근거: docs/문제정의.md v2 (정한 범위: 사용자와 권한), docs/IA.md (유저 플로우 "처음 로그인한 사람"), docs/adr/0002
- 근거 수준: **가설**. 발표 때 청중이 직접 로그인하는 상황을 가정한다.

## 개요
| 항목 | 내용 |
|---|---|

## Moment of Truth
- **2. 열람자 도착:** 아무 설명 없이 버튼만 없으면 "고장 났다"고 느낍니다. 발표 때 청중이 처음 보는 장면이라 인상이 여기서 갈립니다.

## 여정 명세 요점
- 구글 로그인 창을 닫거나 실패하면 로그인 화면으로 돌아와 "로그인하지 못했습니다. 다시 시도해 주세요."를 보여 준다.
- 로그아웃하면 로그인 화면으로 간다. 로그인하지 않은 채 다른 주소로 들어오면 로그인 화면으로 보낸다.
- QA 관리자는 자기 역할을 스스로 내릴 수 없다. QA 관리자가 0명이 되는 것을 막기 위해서다. (확정 2026-10-22)
- 사용 기록에 로그인·로그아웃이 남는다 (2차).
