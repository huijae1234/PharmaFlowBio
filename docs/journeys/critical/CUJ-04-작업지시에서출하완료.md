# CUJ-04: 작업지시부터 출하 완료까지 (화면 순서)

- 기준: `main` 2026-10-28 (PR #21까지 합쳐진 기능). **문서 기준이며 실제 화면을 눌러 확인하기 전이다.** 확인하면 아래 "확인 기록"에 적는다.
- 근거: spec 008(검체 인계), 009(알림), 010(작업지시), 011(공정 단계), 017(시험 완료·출하 완료), docs/IA.md v2.11, docs/PRD.md FR-43~45
- 목적: CUJ-01~03이 다루지 않은 앞뒤(생산 시작, 검체, 시험 완료, 출하 완료)를 이어 "일을 끝내기까지의 화면 순서"를 한 줄로 보인다. 이탈이 생기는 길은 CUJ-01·02가 자세히 다룬다.
- 핵심 사용자: 생산 담당자, QC 시험 담당자, QA 관리자

매 단계가 업무 이력(`BT_010204_TB`, QA 관리자는 `AD_030000_PG`)에 한 줄씩 남고, 고치거나 지울 수 없다.

## 이 문서가 다루지 않는 것
- 출하 완료는 회사 내부 기록이다. 국가출하승인과는 다르다(PRD 하지 않을 것).
- 9번의 이탈 처리는 CUJ-01·02가 자세히 다룬다. 여기서는 위치만 표시한다.
- `main`에 아직 합쳐지지 않은 기능은 넣지 않았다.
