CUJ (Critical User Journey)

CUJ-01 백신 로트 시험 이탈부터 내부 출하 검토까지 (v2)

백신 로트의 시험 결과가 기준을 벗어났을 때, 나는 이탈 근거·품질 영향 평가·조치·승인 이력을 한곳에서 보고 싶다. 그래서 놓친 것 없이 1분 안에 내부 출하 검토를 할 수 있다.
페르소나QA 관리자 (보조: QC 시험 담당자)
시나리오가상 백신 로트 VX-2610-003의 역가 시험값이 사내 관리기준은 물론 시험 규격까지 벗어남 (교육용 가상 값)
근거가설 — 실제 사용자·데이터 없음. 발표 전 2~3명 시연 사용으로 감정·시간을 확인
1. 시험값 입력
2. 이탈 감지MOT
3. 품질 영향 평가
4. QA 검토
5. 조치·이슈 종료
6. 내부 출하 검토MOT
행동
QC 시험 담당자가 품질시험 홈에서 로트를 열고 시험값 입력
저장하자 규격 이탈 판정, 품질 이슈(규격 이탈)가 열리고 로트가 보류됨. 관리기준만 벗어나면 이슈만 열림
담당자가 품질 이슈 상세에서 이탈 내용·추정 원인·품질 영향·제안 조치·근거를 적어 검토 요청
QA 관리자가 영향 평가를 승인·반려·보완 요청하고, 재시험 조치 요청을 승인(담당자 배정)
배정된 담당자가 재시험 결과 입력 → 정상이면 이슈를 닫음 (승인된 영향 평가 + 완료된 조치)
QA 관리자가 로트 상세 위쪽 요약에서 열린 이슈 0건·판정 근거·이력을 확인하고 출하 가능 결정
터치포인트
품질시험 홈, 로트 상세 > 시험값 입력
시험 결과 탭, 상태 배지, 판정 근거(기준·버전)
품질 이슈 상세 > 품질 영향 평가 작성
관리자 대시보드, 승인 대기, 품질 영향 평가 검토, 조치 요청 승인
품질 이슈 상세 > 조치 결과 입력, 이슈 닫기
로트 상세 > 내부 출하 검토

감정 곡선
As-Is (엑셀·메일·종이 기록)
시험 기록지에 적고 기준서와 눈으로 비교
담당자가 메일·전화로 QA에 알림. 빠뜨리기 쉬움
워드 양식에 손으로 옮겨 적고 메일 첨부
메일함에서 평가서·요청서를 따로 찾아 회신
재시험 결과를 별도 기록지에 작성
시험·생산 기록, 평가서, 메일, 엑셀을 따로 뒤져 확인 (15분~3~4시간, 인터뷰 가정, 가정)
페인포인트
이탈 사실과 판정 근거가 사람 손으로 전달되어 누락·지연
평가 승인과 출하 승인이 섞여 '특채'로 오해될 위험
As-Is 감정 최저점: 놓친 이탈이나 승인 안 된 평가가 있을까 불안
인사이트
자동으로 이슈를 열고, 규격 이탈만 보류해야 과잉 보류 없이 누락을 막음
영향 평가 승인은 출하 승인이 아님을 화면과 규칙으로 분리
또 이탈이어도 같은 이슈에 붙어 맥락이 이어져야 불안이 줄어듦
열린 이슈가 있으면 출하 가능을 막고, 국가출하승인이 아님을 분명히 해야 신뢰가 생김
기회·개선안
시험 규격·사내 관리기준을 입력 칸 옆에 보여 주고 저장 즉시 세 단계 판정
세 단계 판정 + 이슈 자동 생성 + 규격 이탈 자동 보류 + 기준 버전 기록
로트·발생 일시·시험 항목·측정값·적용 기준과 버전 자동 표시
승인 대기에 평가·조치 함께, 승인 모달에 '사용·출하 승인 아님' 표시
같은 이슈에 결과 누적, 닫기 조건을 글로 안내
요약 + 다음에 할 일 + 버튼 잠금 + '국가출하승인 아님' 안내

핵심 발견

  • MOT 1 — 이탈 감지: 자동으로 이슈를 열되 규격 이탈만 보류해야 누락도 과잉 보류도 없다
  • MOT 2 — 내부 출하 검토: 판정 근거(기준·버전)·영향 평가·조치·이력이 한 화면에 있어야 1분 안에 끝난다. 영향 평가 승인이 출하 승인처럼 보이면 안 된다
  • 모든 감정·시간은 가설. 발표 전 2~3명에게 시연해 확인한다
