# Vercel 함수로 공공데이터를 대신 호출한다

공공데이터포털 API(허가정보, 회수·판매중지, MSDS)를 실시간으로 쓰기로 했다. 브라우저에서 바로 부르면 인증키가 화면 코드에 드러나므로, 화면은 빌드 없는 HTML/JS로 두고 `api/` 폴더의 Vercel 함수가 키를 붙여 대신 부른다. 인증키는 Vercel 환경변수와 로컬 `.env`에만 둔다. 내 PC에서는 Vercel 프로그램을 설치하지 않고, Node 기본 기능으로 만든 작은 서버가 같은 `api/` 함수를 돌린다. MSDS API는 XML만 주므로 함수에서 JSON으로 바꿔 넘긴다.

## 검토한 다른 방법
- 미리 받아 둔 JSON 스냅샷만 쓰기: 가장 쉽지만 사용자가 실시간 연동을 원했다.
- 이 PC의 Python 프록시: 노트북 시연에는 충분하지만, 청중이 인터넷 주소로 직접 들어오는 발표 방식에 맞지 않는다.

## 주의할 점
- 클라우드 서버 요청 차단 여부: 2026-10-22 Vercel 서울(icn1) 함수에서 확인했고 **막지 않는다** (허가정보·회수 API resultCode 00).
- 대신 공공데이터 응답이 0.5초에서 15초 넘게까지 들쭉날쭉하다 (PC와 Vercel 모두). 화면 대응은 Intent Q14.
- Vercel이 `package.json`의 start 명령을 보고 Node 서버 앱으로 오인하므로 `vercel.json`에 `framework: null`을 둔다.
- 개발계정 트래픽 한도: 허가정보·회수 10,000건, MSDS 2,000건.
