# 포트폴리오 리드미 화면

- 촬영일: 2026-11-02 (Asia/Seoul)
- 출처: 팀 배포 서비스 https://pharmaflow-iota.vercel.app
- 방식: 기존 로그인 세션의 열람자 권한으로 실제 화면을 열어 ego-browser로 촬영. 01은 1440×1000, 02·03은 1724×957 이미지다.
- 발표 슬라이드, 가짜 업무 화면, 가짜 API 응답은 사용하지 않았다.
- 개인정보 처리: 캡처 직전 화면의 계정 표시를 ‘포트폴리오 열람 계정’으로, 이슈 화면의 팀원 이름을 ‘담당자 A/B/C’로 바꿨다. 화면 DOM에만 적용했으며 서버의 기록·권한·데이터는 수정하지 않았다. 이 외 화면 내용과 수치는 변경하지 않았다.

| 파일 | 내용 | 확인 범위 |
|---|---|---|
| 01-lot-overview.png | 열람자 첫 화면인 로트 목록·상태 필터·공정 미리보기 | 실제 업무 자료는 교육용. QA 관리자 홈의 캡처가 아님 |

국가출하승인의 과거 성공 기록은 docs/data-source.md 6절의 2026-10-29 팀 확인 기록에 있다. 이번 촬영에서는 성공을 재확인하지 못했다. GMP 유효기간과 남은 일수는 촬영 시점 값이며, 실제 제조소의 현재 적합 여부를 이 문서가 보증하지 않는다.

이번 작업에서는 운영 DB 쓰기, 역할 변경, AI 유료 호출, Slack 발송을 수행하지 않았다.
