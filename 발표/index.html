판단 규칙표

번호들어가는 데이터규칙나오는 판단
J-1시험값, 규격, 관리기준규격 밖 = 규격 이탈, 관리기준 밖 = 관리기준 이탈, 경계는 안쪽정상 / 관리기준 이탈 / 규격 이탈
J-2J-1 판정정상이 아니면 이슈 생성, 규격 이탈만 자동 보류이슈, 로트 보류
J-3로트 상태, 열린 이슈, 최근 시험값열린 이슈·미완료 항목이 있으면 출하 가능 선택 불가차단 + 이유 문장
J-4이슈, 조치, 영향 평가승인된 평가 + 끝난 조치가 있어야 종결종결 가능 여부
J-5이슈·평가·조치 상태5단계와 "다음에 할 일"단계 표시
J-6종결 이슈의 시각평균 처리 일수의 분모 = 종결 이슈 수대시보드 숫자

J-6 직접 확인 종결 3건의 걸린 시간 1.848 · 0.010 · 3.917일(합 5.774일) ÷ 3 = 1.925 → 1.9일, 화면 "평균 처리 1.9일"과 일치 (직접 계산, 2026-10-29). 처리 중 이슈 건수도 이슈 목록과 일치.
종결 시각은 이슈 상세의 "발생"·"종결됨" 시각 기준, 화면에는 초가 안 보여 반올림 한계 존재

근거: docs/03-data-or-automation.md 1절(AI 칸은 6절). 예시 3.9일 손계산과 함수 계산 일치.
